  <files>src/db/entries.rs</files>
  <action>
1. Add `search_by_hashtag(&self, tag: &str) -> Result<Vec<DiaryEntry>>`:
   - SQL: `SELECT ... FROM diary_entries WHERE content LIKE '%#' || ?1 || '%' ORDER BY date DESC, start_time`
   - Tag parameter should NOT include the # prefix (strip it before calling)
   - Use LIKE with wildcards for substring match

2. Add `search_by_text(&self, query: &str) -> Result<Vec<DiaryEntry>>`:
   - SQL: `SELECT ... FROM diary_entries WHERE content LIKE '%' || ?1 || '%' ORDER BY date DESC, start_time`
   - Case-insensitive: SQLite LIKE is case-insensitive for ASCII

3. Both methods return entries with date field populated so results can show which day each entry is from

Note: Use `prepare_cached` for performance on repeated searches
  </action>


3. In app.rs, handle search:

5. Clear search: When query becomes empty, set search_results = None to return to day view

6. Add header indicator: Show "🔍 Searching..." or result count when searching
