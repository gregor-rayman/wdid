1. In src/config/types.rs, add:
   ```rust
   #[derive(Serialize, Deserialize, Default, Clone, Debug)]
   pub struct WindowState {
       pub width: Option<f32>,
       pub height: Option<f32>,
       pub x: Option<f32>,  // X11 only, None on Wayland
       pub y: Option<f32>,
   }
   ```

2. In src/config/mod.rs, add functions:
   - `load_window_state(path: &Path) -> WindowState` - Read from file, return default if missing
   - `save_window_state(path: &Path, state: &WindowState) -> Result<()>` - Write to file
   
   Use toml for serialization (already in deps). Path should be `~/.config/wdid/window_state.toml`.
   
   Add `use serde::Serialize;` if not present. Export WindowState from mod.rs.
  </action>
  <verify>cargo check compiles without errors</verify>
  <done>WindowState type exists with load/save functions</done>
</task>

<task type="auto">
  <name>Task 2: Load window state on startup</name>
  <files>src/main.rs, src/paths.rs</files>
  <action>
1. In src/paths.rs, add `pub window_state_file: PathBuf` to AppPaths struct, initialized to `config_dir.join("window_state.toml")`.

2. In src/main.rs:
   - Load AppPaths at start
   - Call `load_window_state(&paths.window_state_file)` 
   - Use loaded values in NativeOptions:
     ```rust
     let (width, height) = (state.width.unwrap_or(800.0), state.height.unwrap_or(600.0));
     let viewport = ViewportBuilder::default()
         .with_inner_size([width, height])
         .with_min_inner_size([400.0, 300.0]);
     // Only set position on X11 (check WAYLAND_DISPLAY env var is NOT set)
     let viewport = if std::env::var("WAYLAND_DISPLAY").is_err() {
         if let (Some(x), Some(y)) = (state.x, state.y) {
             viewport.with_position([x, y])
         } else { viewport }
     } else { viewport };
     ```
  </action>
  <verify>cargo run starts with previously saved window size (or defaults)</verify>
  <done>Window geometry loaded from file on startup</done>
</task>

<task type="auto">
  <name>Task 3: Save window state on exit</name>
  <files>src/app.rs</files>
  <action>
1. Add `window_state_file: PathBuf` field to WdidApp, passed from main.rs.

2. Implement `on_exit` method for WdidApp to save window state:
   ```rust
   fn on_exit(&mut self, _gl: Option<&eframe::glow::Context>) {
       // Get current viewport info would need to be captured earlier
       // since on_exit may not have full context
   }
   ```

   **Better approach:** Save periodically during `update()`:
   - Add `last_window_save: Instant` field
   - Every 5 seconds, read viewport info via `ctx.input(|i| i.viewport())`:
     - `inner_rect` for size
     - `outer_rect` for position (X11 only)
   - Save if changed from last saved values
   - Also save on close detection (before hide for tray in Plan 02)

3. The `ctx.input(|i| i.viewport())` returns `ViewportInfo` with:
   - `inner_rect: Option<Rect>` - window content area
   - `outer_rect: Option<Rect>` - window including decorations

   Only save position if not Wayland: check `std::env::var("WAYLAND_DISPLAY").is_err()`.
  </action>
  <verify>Resize window, quit app, restart - window appears at saved size</verify>
  <done>Window state persists across restarts</done>
</task>
