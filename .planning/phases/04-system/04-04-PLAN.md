The core issue: egui's `ViewportCommand::Visible(false)` doesn't work reliably, and `close_requested()` is a one-shot flag that may clear before `update()` runs.

Solution: Use GTK APIs directly on Linux (like the Windows approach in egui GitHub discussions).

**Step 1: In src/main.rs, extract raw window handle in eframe::run_native callback:**

```rust
use winit::raw_window_handle::{HasWindowHandle, RawWindowHandle};

eframe::run_native(
    "wdid",
    options,
    Box::new(move |cc| {
        // Get raw window handle for direct visibility control
        if let Ok(handle) = cc.window_handle() {
            if let RawWindowHandle::Xlib(xlib_handle) = handle.as_raw() {
                // Store Xlib window ID in tray module
                crate::tray::set_window_handle(xlib_handle.window as u64);
            }
        }
        Ok(Box::new(WdidApp::new(cc, paths, tray_rx)))
    }),
)
```


**Alternative approach (simpler):** Store the egui Context in a static and call request_repaint() from tray events to ensure update() runs:

```rust
use std::sync::OnceLock;
static EGUI_CTX: OnceLock<egui::Context> = OnceLock::new();

// In WdidApp::new or update():
EGUI_CTX.get_or_init(|| ctx.clone());

// In tray event handler:

    ctx.request_repaint();
}
```

This ensures update() runs even when window is hidden, so tray commands get processed.

The close_requested() approach may work if we ensure update() is called immediately.

**Approach:** Store egui Context globally and call request_repaint() when tray events occur.

**In src/tray.rs:**
```rust
use std::sync::OnceLock;
static EGUI_CTX: OnceLock<egui::Context> = OnceLock::new();

pub fn set_egui_context(ctx: egui::Context) {
    EGUI_CTX.get_or_init(|| ctx);
}

// In event handlers after sending TrayCommand:
if let Some(ctx) = EGUI_CTX.get() {
    ctx.request_repaint();
}
```

**In src/app.rs update() - at the very start:**
```rust
fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
    // Store context for tray module to request repaints
    crate::tray::set_egui_context(ctx.clone());

    // Handle close-to-tray FIRST
    if ctx.input(|i| i.viewport().close_requested()) {
        ctx.send_viewport_cmd(egui::ViewportCommand::CancelClose);
        ctx.send_viewport_cmd(egui::ViewportCommand::Visible(false));
        crate::tray::set_visible(false);
        self.save_window_state_if_changed(ctx);
        return; // Don't process rest of update when hiding
    }
    // ... rest of update
}
```

If close_requested() still doesn't work, the fallback is to disable the close button and add a custom title bar button, but try the request_repaint approach first.
