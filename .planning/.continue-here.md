<decisions_made>
## Architecture
- egui/eframe for GUI (immediate mode, good Linux support)
- SQLite with WAL mode for persistence
- ksni for system tray (freedesktop standard)
- tokio for async calendar fetching

## Wayland Workarounds
- ViewportCommand::Minimized instead of Visible(false) for hide/show
- screen_rect() fallback for window state persistence

## Export Design
- Clipboard via arboard, file dialogs via rfd
- Standup format: bullet list with durations
- Weekly retro: grouped by day with totals
</decisions_made>
